# Code of Conduct

DeskCron is intended to be a practical, welcoming open-source project.

Be respectful, keep technical discussion focused on the work, assume good intent, and avoid harassment, discrimination, personal attacks or disclosure of private information.

Project maintainers may edit or remove comments, issues, pull requests or other contributions that materially disrupt the project or violate these expectations. Serious or repeated abuse may result in temporary or permanent exclusion from project spaces.

For conduct concerns that should not be handled in a public issue, contact the maintainer privately through the GitHub profile associated with this repository.
